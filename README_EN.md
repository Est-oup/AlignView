# AlignView

Linux/SSH terminal workbench for sequences, local and VSEARCH searches, alignments, translation and standalone HTML/SVG reports. Python 3.10+; no required third-party Python packages.

```bash
/path/to/AlignView/alignview.sh --lang en --demo
/path/to/AlignView/alignview.sh --lang en --docs quickstart
```

Copy the complete AlignView/ folder. Launch from your data directory to keep relative outputs there. Use --save --out DIRECTORY for a resumable project, --html-out FILE.html for one standalone report, or --export-dir DIRECTORY for exports. --out alone does not save, and --report alone prepares temporary HTML.
